# 🩸 DonorMate SL

DonorMate SL is an iOS mobile application designed to make blood donation easier, more accessible, and more organized in Sri Lanka.

The application helps blood donors track their donation history, check their next eligible donation date, find nearby blood donation locations, and stay informed about urgent blood requirements.

## Features

- **Donor Accounts** – Secure registration and sign-in.
- **Donation History** – View previous blood donations and donation details.
- **Donation Readiness** – Check when the next blood donation is possible.
- **Nearby Locations** – Find blood banks and donation camps using an interactive map.
- **Location Alerts** – Receive notifications about nearby donation opportunities.
- **Urgent Blood Needs** – View and save urgent blood donation requests.
- **Notifications** – Receive important donation updates and reminders.
- **Donation Guidance** – Access helpful information about blood donation.
- **Home Screen Widget** – Quickly view donation readiness from the iPhone Home Screen.
- **Identity Verification** – Support donor identity verification using document scanning.

## Project Purpose

DonorMate SL aims to encourage voluntary blood donation and improve the overall experience for blood donors through a simple and user-friendly mobile application.

## Project Information

- **Project Name:** DonorMate SL

## Disclaimer

This application was developed for educational purposes. Some features use demonstration data and are not connected to official blood bank services.
